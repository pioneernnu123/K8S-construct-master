## 安装策略

安装脚本采用原位升级方式：node-agent 会覆盖同名程序和 systemd 单元后重启，controller 会先阻止在旧 `DirectWorkload` 未回收时升级，监控使用 Helm `upgrade --install`。因此先盘点和正常回收旧任务，再按 README 的节点角色安装；不在未确认业务状态时直接删除 Kubernetes 或 containerd 数据。
